# Système de vote : le front (mai 2021)

L'interface React et web3 du défi « système de vote » de la formation Alyra. Le contrat est dans [VoteDefiAlyra](https://github.com/anthonyC77/VoteDefiAlyra).

L'administrateur y fait avancer les étapes et enregistre les électeurs ; les électeurs déposent leurs propositions puis votent, et la page affiche la proposition gagnante. L'interface se connecte au contrat par MetaMask.

```bash
npm install
npm start
```

Exercice de formation, non maintenu.
